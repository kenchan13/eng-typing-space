# 🚀 星際巡邏隊：大寫字母防衛戰 (Space Type Patrol)

一個專為學生設計、以**英文大寫字母打字（掌握雙手 `Shift` 鍵操作）**為核心教學目標的單一 HTML 網頁冒險遊戲。

---

## 🎮 遊戲特點

1. **單一 HTML 檔案 (One HTML File)**：免安裝、免伺服器，直接在任何現代瀏覽器開啟 `index.html` 即可流暢遊玩。
2. **全 5 關單一大寫字母 (Single Capital Letter Practice)**：
   - 全 5 關全面採用單一大寫字母，下落速度**大幅放慢**，給學生充裕的反應時間對照指法。
   - 每關剛好 40 擊（每按對 1 個大寫字母 = 射擊 1 次 = 得 1 分，每關滿分 40 分，總分 200 分）。
3. **經典落下式射擊 (Space Invaders)**：大寫裝甲機由螢幕上方極慢速飄落，在撞擊基地防護罩前精準充能擊滅。
4. **智能 Shift 指法導引與全輸入法相容**：
   - 底部智慧鍵盤**對稱高亮對應的 Shift 鍵**（打右手字母亮左手 Shift，打左手字母亮右手 Shift）。
   - 採用底層鍵碼識別技術，完全免疫中文輸入法（倉頡、注音、拼音等）干擾。
   - 同時支援滑鼠或觸控點擊螢幕上的虛擬按鍵，支援平板與觸控螢幕！
   - 頂部 HUD 提供快捷選關下拉選單（Level 1 ~ 5），方便隨時挑選測試。
5. **原生 Web Audio 程式合成音效**：內建雷射射擊、充能重砲、護盾彈開、爆炸與通關號角等 5 種復古街機音效，零外載依賴。

## 🌐 GitHub Pages 線上試玩設定

本專案上傳至 GitHub 後，可直接開啟 GitHub Pages 免費託管：
1. 進入 GitHub Repository 的 **Settings**。
2. 在左側選單點選 **Pages**。
3. 在 **Branch** 選項選擇 `main` 分支與 `/(root)` 目錄，點擊 **Save**。
4. 稍等數十秒即可獲得線上遊玩網址：  
   `https://kenchan13.github.io/eng-typing-space/`

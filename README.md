# 🚀 星際巡邏隊：字母防衛戰 (Space Type Patrol)

一個專為學生設計、以**英文大小寫打字（特別是掌握 `Shift` 鍵操作）**為核心教學目標的單一 HTML 網頁冒險遊戲。

---

## 🎮 遊戲特點

1. **單一 HTML 檔案 (One HTML File)**：免安裝、免伺服器，直接在任何現代瀏覽器開啟 `index.html` 即可流暢遊玩。
2. **經典落下式射擊 (Space Invaders)**：目標由螢幕上方緩慢降落，學生需在目標撞擊基地防護罩前精準擊發。
3. **逐字命中計分制 (One Correct Shot = 1 Mark)**：
   - 每按對 1 個字母即射擊 1 次，獲得 1 分。
   - **每關剛好 40 擊（滿分 40 分）**，五大關卡總分 200 分。
4. **智能 Shift 指法導引**：
   - 遇到大寫字母時，螢幕底部虛擬鍵盤會**對稱高亮對應的 Shift 鍵**（打右手字母亮左手 Shift，打左手字母亮右手 Shift）。
   - 若只按小寫字母未按 Shift，雷射會被護盾彈開並發出提示，目標不扣血。
   - 若開啟 Caps Lock 會自動跳出警示，引導正確盲打肌肉記憶。
5. **原生 Web Audio 程式合成音效**：內建雷射射擊、充能重砲、護盾彈開、爆炸與通關號角等 5 種復古街機音效，零外載依賴。

---

## 🕹️ 五大關卡架構

| 關卡 | 關卡名稱 | 學習核心重點 | 目標類型 | 滿分 |
| :---: | :--- | :--- | :--- | :---: |
| **Lv.1** | **能量護盾初試** | 大寫字母（Capital Letters） | 帶有光環護盾的裝甲機，按住 `Shift` 充能擊發 | **40 分** |
| **Lv.2** | **近地浮石清掃** | 小寫字母（Small Letters） | 太空隕石群，放開 Shift 進行平穩節奏射擊 | **40 分** |
| **Lv.3** | **雙子星混合波** | 大小寫即時快速切換 | 大小寫目標穿插交替，訓練雙手切換反應 | **40 分** |
| **Lv.4** | **星際導航解碼** | 首字大寫實用單字 | 信標巡航艦（如 `Sun`, `Mars`, `Earth`），首字大寫其餘小寫 | **40 分** |
| **Lv.5** | **終極母艦決戰** | 外星代碼與縮寫綜合挑戰 | 旗艦與複合縮寫代碼（如 `NASA`, `Rocket`, `Galaxy`） | **40 分** |

## 🌐 GitHub Pages 線上試玩設定

本專案上傳至 GitHub 後，可直接開啟 GitHub Pages 免費託管：
1. 進入 GitHub Repository 的 **Settings**。
2. 在左側選單點選 **Pages**。
3. 在 **Branch** 選項選擇 `main` 分支與 `/(root)` 目錄，點擊 **Save**。
4. 稍等數十秒即可獲得線上遊玩網址：  
   `https://<你的 GitHub 帳號>.github.io/<倉庫名稱>/`

# 🚀 星際巡邏隊：大寫字母防衛戰 (Space Type Patrol)

一個專為學生設計、以**英文大寫字母打字（掌握雙手 `Shift` 鍵操作）**為核心教學目標的單一 HTML 網頁冒險遊戲。

---

## 🎮 遊戲特點

1. **單一 HTML 檔案 (One HTML File)**：免安裝、免伺服器，直接在任何現代瀏覽器開啟 `index.html` 即可流暢遊玩。
2. **每關 60 秒限時挑戰 (60s Timed Survival Mode)**：
   - 告別固定打滿 40 架敵機的疲勞感，改為刺激且容易掌控課堂時間的 **1 分鐘（60 秒）防衛戰**。
   - 學生只需在 60 秒倒數計時結束前守護基地防護罩，擊落越多的敵機獲得越高的成就！
3. **第 1 關敵機數量減半 (Reduced Airplane Count)**：
   - **Level 1 畫面上永遠僅有 1 架敵機**（原本 2~3 架減半），以極超慢速飄落，讓初學者完全零壓力、專注單一字母指法。
   - 後續關卡依序適度微調上限（Lv.2: 2架、Lv.3: 2架、Lv.4: 3架、Lv.5: 4架），難度平滑遞進。
4. **五大關卡專屬特色宇宙背景 (Custom Level Background Themes)**：
   - **Lv.1 地球軌道**：深藍星空與弧形地球大氣層輝光。
   - **Lv.2 火星帶**：赤褐星系、遠方火星與漂浮碎石小行星。
   - **Lv.3 紫晶星雲**：紫羅蘭電磁星雲雲氣流動。
   - **Lv.4 雙子星系**：耀金雙子恆星與熾熱日冕光暈。
   - **Lv.5 超空間決戰**：光速躍遷星芒條紋與母艦透視網絡矩陣。
5. **智能 Shift 指法導引與全輸入法相容**：
   - 底部智慧鍵盤**對稱高亮對應的 Shift 鍵**（打右手字母亮左手 Shift，打左手字母亮右手 Shift）。
   - 採用底層鍵碼識別技術（`e.code`），完全免疫中文輸入法（倉頡、注音、拼音等）干擾。
   - 支援滑鼠/觸控點擊虛擬鍵盤，適配平板與觸控螢幕。
   - 頂部 HUD 提供快捷選關下拉選單（Level 1 ~ 5），方便隨時挑選測試。
6. **原生 Web Audio 程式合成音效**：內建雷射射擊、護盾彈開、爆炸、撞擊與通關號角等 5 種復古街機音效，零外載依賴。

## 🌐 GitHub Pages 線上試玩設定

本專案上傳至 GitHub 後，可直接開啟 GitHub Pages 免費託管：
1. 進入 GitHub Repository 的 **Settings**。
2. 在左側選單點選 **Pages**。
3. 在 **Branch** 選項選擇 `main` 分支與 `/(root)` 目錄，點擊 **Save**。
4. 稍等數十秒即可獲得線上遊玩網址：  
   `https://kenchan13.github.io/eng-typing-space/`
